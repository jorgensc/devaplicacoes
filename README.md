# Projeto CRUD – Django e MySQL

Projeto desenvolvido em Python utilizando o framework Django e banco de dados MySQL,
conforme atividade problematizadora da disciplina Desenvolvimento de Aplicações.

## Funcionalidades
- Cadastro de funcionários
- Listagem de registros
- Edição de dados
- Exclusão de registros

## Tecnologias utilizadas
- Python
- Django
- MySQL (XAMPP)
